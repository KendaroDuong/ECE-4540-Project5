# Layout outputs

Put finished layout outputs here, then commit and push:

- `MAJ3.lef`, `ONEHOT3.lef`
- `MAJ3_extracted_netlist.scs`, `ONEHOT3_extracted_netlist.scs`
- `dimensions.txt`: width, height, width in sites, area, library name, extracted view name

Screenshots go in `../screenshots/`, named after their figure, such as `fig_2_1_MAJ3_layout.png`.
